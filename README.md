# DT-boolsche-Algebra-Test

Test-Repository für eine Webseite, die die boolesche Algebra einfach und übersichtlich erklärt.

- `index.html` – einzelne, offline funktionierende Webseite (Darkmode, interaktiver Rechner, Quiz)
- Inhalt u. a. nach Lipp/Becker, *Grundlagen der Digitaltechnik*, 7. Aufl., Oldenbourg 2011 (Kap. 5.4 & 6)
- CI: GitHub Actions testet bei jedem Push/PR die Seite (`node tests/check-page.js`, Workflow: `.github/workflows/ci.yml`)
